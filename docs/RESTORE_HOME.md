# نقطة استعادة الواجهة الرئيسية القديمة

**السبب:** الخطوة BQ (19 نوفمبر 2026) استبدلت غلاف الصفحة الرئيسية القديم (`section.cover`: شعارات الجهات، المصباح، «أهلًا بكم في مركز سما القدرات للتدريب»، العدّادات) بالقسم العلوي الجديد (`section.nh`: صورتا قسمي البنين والبنات، المبدّل، البطاقات الزجاجية). طلب المالك إبقاء نقطة استعادة إن طلبت إدارة المركز العودة إلى الواجهة القديمة.

**نقطة الاستعادة:** الفرع `restore/home-cover-v1` على GitHub = آخر نسخة من `main` قبل الدمج (الالتزام `d5c93cf`). لا يُحذف هذا الفرع.

## طريقة الاستعادة (اختر واحدة)
1. **التراجع عن طلب الدمج (المفضّل):** من صفحة طلب دمج الخطوة BQ على GitHub اضغط **Revert**، ثم ادمج طلب التراجع. يُعيد الغلاف القديم ويُبقي كل ما دُمج بعده.
2. **سطر الأوامر:**
   ```
   git checkout -b restore-old-home origin/main
   git revert <التزام الخطوة BQ في main>
   npm run check
   ```
   ثم طلب دمج كالمعتاد.
3. **نسخ الملفات القديمة وحدها:** `git checkout restore/home-cover-v1 -- src/landing.js` ثم احذف كتلة «معاينة: القسم العلوي الجديد» من آخر `src/style.css`، وأزل فحوص «الخطوة BQ» من `tests/home_courses.mjs`، وصورتي `public/home/`.

بعد الاستعادة يعود النشر على GitHub Pages تلقائيًا عند الدمج.
