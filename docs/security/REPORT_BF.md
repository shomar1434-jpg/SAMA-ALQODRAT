## سليم دون تغيير
المصادقة وتشفير كلمات المرور (Supabase، bcrypt)؛ RLS على كل الجداول؛ الاستعلامات بمعاملات؛ لا مفاتيح سرية في الكود ولا في تاريخ Git (المفتاح العام anon فقط وهو عام بطبيعته)، فلا مفتاح يحتاج إلغاء؛ حدود المحاولات (الدخول، ربط ولي الأمر، أبلغوني)؛ سجل الحركات الإلحاقي؛ المبالغ يحسبها الخادم؛ لا وضع تشخيص في الإنتاج؛ الجلسة رمز Bearer لا كوكيز، فـCSRF غير منطبق.
