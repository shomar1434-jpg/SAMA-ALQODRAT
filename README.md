# منصة التسجيل والحضور — مركز سما القدرات للتدريب

- تسجيل المتدربين في دفعات البرامج المعتمدة وباقات القدرات والتحصيلي.
- تحضير يومي بباركود ثابت والتحقق برقم السجل المدني.
- لوحة إدارة: الدفعات، والمتابعة، وآلية احتساب الحضور، والتقارير والطباعة، والشهادات.

## التشغيل محليًا
```
npm install
npm run dev
```
افتح الرابط الذي يظهر. الصفحة العامة على `/`، ولوحة الإدارة على `/admin/` (رمز الدخول التجريبي: 1234).
بدون مفاتيح Supabase تعمل المنصة ببيانات تجريبية في المتصفح.

## الفحص
```
npm run check    # فحص ثابت + بناء + اختبارات المتصفح
```
يعمل الفحص نفسه تلقائيًا على GitHub مع كل دفع (`.github/workflows/ci.yml`).

## الربط بـ Supabase (الخطوة 14 من الخطة)
1. طبّق `supabase/migrations/` ثم `supabase/seed.sql`.
2. أنشئ مستخدم المسؤول وأضف معرّفه إلى جدول `admins`.
3. انسخ `.env.example` إلى `.env.local` وضع `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`، ثم `npm run build`.
