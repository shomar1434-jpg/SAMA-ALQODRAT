# منصة التسجيل والحضور — مركز سما القدرات للتدريب

- تسجيل المتدربين في دفعات البرامج المعتمدة.
- تحضير يومي بباركود ثابت لكل برنامج والتحقق برقم السجل المدني.
- لوحة إدارة: الدفعات، والمتابعة، وآلية احتساب الحضور، والتقارير والطباعة، والشهادات.

## التشغيل محليًا
افتح `index.html` في المتصفح. يعمل بالبيانات التجريبية (رمز الإدارة: 1234).

## الربط بـ Supabase
1. طبّق `supabase/migrations/` ثم `supabase/seed.sql` (`supabase db push` أو من SQL Editor).
2. أنشئ مستخدم المسؤول من Authentication، وأضف معرّفه إلى جدول `admins`.
3. ضع `SUPABASE_URL` و`SUPABASE_ANON_KEY` أعلى السكربت في `index.html`.

## النشر
GitHub Pages من الفرع الرئيسي (الملف `index.html` في الجذر).

## التطوير
عدّل `src/` ثم `python build.py`. التفاصيل في `CLAUDE.md`.
